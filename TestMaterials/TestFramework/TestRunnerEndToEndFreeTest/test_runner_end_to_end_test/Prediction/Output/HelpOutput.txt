Usage: TestAll [command] [options]

Commands:
  test, t <suite>                       Run the tests of a suite: a directory beneath Tests
  select, s <source>                    Run the test defined in a source file
  prune, p                              Run the tests affected by changes since the previous run
  create, c [command] [options]         Create a test; the command names its kind
  init, i <owner> <path> <indent> [options]
                                        Create a project at the path, named after its last directory
  update-materials, u                   Run the tests, accepting each working copy as its prediction
  locate-instabilities, locate <repetitions> [options]
                                        Run the tests repeatedly, reporting the checks whose outcome varies
  recover                               Run serially, recording each check before it runs, to find a crash
  dump [options]                        Run serially, recording every check, for comparing two runs

Options:
  --check-versioned-output              Fail the run if it changes anything versioned under output
  --exclude-performance                 Leave out the performance tests
  --exclude <source>                    Leave out the test defined in a source file
  --serial                              Run the tests on one thread
  --thread-pool <threads>               Run the tests on a pool of the given number of threads
  --verbose, -v                         Print the suites and their tests as a tree
  --help, -h                            Describe the command or option this follows; alone, the top level
