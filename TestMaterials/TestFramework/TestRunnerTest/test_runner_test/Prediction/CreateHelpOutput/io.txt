Usage: FakeExe create [command] [options]

Create a test; the command names its kind
A class is spelt with its namespace and template parameters, as in foo::bar<class T>; an allocation test takes its bare name

Commands:
  regular_test, regular <class> <equivalent_type> [options]
                                        A regular test of the class against an equivalent type
  move_only_test, move_only <class> <equivalent_type> [options]
                                        A move-only test of the class against an equivalent type
  regular_allocation_test, regular_allocation, allocation_test <class> [options]
                                        An allocation test of the regular class
  move_only_allocation_test, move_only_allocation <class> [options]
                                        An allocation test of the move-only class
  free_test, free <header> [options]    A test of the free functions the header declares
  performance_test, performance <header> [options]
                                        A performance test of what the header declares

Options:
  --help, -h                            Describe the command or option this follows; alone, the top level
