Usage: FakeExe create regular_test <class> <equivalent_type> [options]

A regular test of the class against an equivalent type

Options:
  --header <header>             Name the header declaring the class under test
  --gen-source, -g <dir>        Generate the class's header and source too, under Source/<dir>
  --fullname <name>             Name the test class <name> exactly, and its files after it
  --testing-utilities <header>  Take the value_tester from an existing header beneath Tests; a regular or move-only test then generates neither testing utilities nor false-negative diagnostics
  --help, -h                    Describe the command or option this follows; alone, the top level
